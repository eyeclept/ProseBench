## Rule 3: Redundant antonym trailer (ordinary-knowledge test)

A trailing "not X" or "rather than X" clause tacked onto a sentence is a problem either way, just for different reasons. Apply the ordinary-knowledge test first: is X the ordinary, general-knowledge antonym of the term just used, something virtually anyone would already know without domain background (on purpose/by accident, true/false, alive/dead, permanent/temporary)? If yes, the trailer adds nothing: cut it. If no, the trailer is smuggling a genuine, checkable distinction into a bolted-on clause instead of giving it the sentence it needs. Taping it on reads poorly regardless of whether the distinction is real; a real distinction earns its own sentence, stated as what the thing is or does, not as what it isn't (see Rule 12, Accuracy and fabrication).

- WRONG (ordinary-knowledge antonym, tacked on): "A tradeoff every one of these systems makes on purpose, rather than by accident."
- RIGHT (cut it): "A tradeoff every one of these systems makes on purpose."
- WRONG (genuine distinction, still tacked on): "A vision paper, not a built system."
- RIGHT (own sentence, stated as fact): "This is a vision paper. The authors propose a design and an evaluation plan; they report no implementation or benchmark results."
- WRONG (genuine distinction, still tacked on): "Built into the database's own cluster, not bolted on as a separate service."
- RIGHT (own sentence, stated as fact): "The feature ships as a module inside the database's existing cluster nodes, deployed with the database itself."

If a case looks like it might fit but you're not sure which side of the test it falls on, don't decide alone: flag it to the user and work through it together. Report the sentence and your uncertainty rather than silently cutting or rewriting it.
